# Purpose

The final e-Portfolio should provide a coherent and reflective account of my work throughout the Intelligent Agents module.

It should not simply reproduce every discussion post, exercise, or project file. Instead, it should:

- present the important outputs from the module;
- provide clear links to supporting evidence;
- explain how my understanding developed;
- evaluate my team and individual project work;
- show how the module learning outcomes were achieved;
- demonstrate critical thinking, collaboration, and professional development.

# Section 11 — Units 11–12: Individual Project — Inquiro

## Project Purpose

Inquiro is a local academic research assistant implemented as a LangGraph workflow with four agent roles:

1. Planner  
2. Retriever  
3. Processor  
4. Writer  

## Evidence Required

### Design and Architecture

### Implementation

- [ ] arXiv integration

### Testing and Evaluation

- [ ] Unit tests
- [ ] Workflow test
- [ ] Functional-test output
- [ ] Screenshots
- [ ] Logs
- [ ] Intermediate artefacts
- [ ] Remediation log

### Supporting Documentation

- [ ] README
- [ ] Requirements
- [ ] Presentation
- [ ] Audio transcript
- [ ] GitHub link

## Suggested Evidence Location

```text
evidence/intelligent-agents/inquiro/
```

## Critical Evaluation Focus

### Design Compared with Implementation

- Proposed use of a broader or more complex architecture.
- Final use of one local Ollama model with different prompts.
- Streamlit and cloud fallback were removed.
- Command-line implementation kept the scope manageable.

### Strengths

- Clear separation of agent responsibilities.
- Local execution and privacy.
- Logs and intermediate outputs.
- Unit and workflow testing.
- Real arXiv retrieval.
- Reproducible project structure.

### Limitations

- Small local model.
- Limited retrieval depth.
- No graphical interface.
- No human approval stage.
- Output quality depends on the search query and retrieved papers.
- Limited time for wider evaluation.

### Lessons Learned

- Testing should begin earlier.
- Simpler architecture improved debugging.
- Logging made the workflow easier to understand.
- Intermediate outputs improved traceability.
- Agent roles do not always require separate models.
