# e-Portfolio Module Workflow

## 1. Read the Module Guidance

### Identify

- Assessment task
- Learning outcomes
- Required activities
- Required artefacts
- Word limits
- Submission format
- Marking criteria

## 2. Decode the Requirement

### Translate into Plain English

- What must I produce?
- What evidence must I show?
- What reflection is required?
- What is optional?
- What is assessed?

### Record in Module Plan

- Required sections
- Evidence list
- Deadlines
- Missing items

## 3. Collect Evidence

### Discussions

- Initial post
- Peer responses
- Feedback received
- Summary post

### Activities

- Written answers
- Code
- Diagrams
- Screenshots
- Outputs

### Projects

- Proposal
- Design
- Implementation
- Testing
- Evaluation

### Professional Development

- Meeting notes
- Feedback
- Skills
- Action plan

## 4. Map the Evidence

### Learning Outcomes

- Which outcome does it support?
- What proves that outcome?
- Is the relationship clear?

### Marking Criteria

- Criticality
- Application of knowledge
- Collaboration
- Academic integrity
- Structure and presentation

## 5. Write the Content

### Describe Briefly

- What did I do?

### Reflect

- What did I learn?
- What was difficult?
- How did my thinking change?
- What would I improve?

### Support

- Add evidence
- Add citations
- Add links or screenshots

## 6. Review the Content

### Check

- Natural writing style
- Evidence included
- Learning outcomes mapped
- References complete
- Word count correct
- No unsupported claims

## 7. Update the Website

### Local Work

- Edit HTML in VS Code
- Preview locally
- Test links
- Check images
- Check mobile layout

### Git

- Review `git status`
- Commit changes
- Push branch
- Merge when ready

## 8. Final Quality Check

### Website

- Navigation works
- Evidence opens
- Text is readable
- No placeholders remain

### Assessment

- Requirements covered
- Reflection complete
- Collaboration evidenced
- References accurate

## 9. Submit

### Turnitin

- Include e-Portfolio URL
- Use correct filename
- Upload one required file
- Verify submission receipt
