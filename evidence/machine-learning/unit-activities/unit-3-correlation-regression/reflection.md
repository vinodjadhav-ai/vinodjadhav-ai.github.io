# Unit 3: Correlation and Regression — Learning Reflection

## What?

I worked through four Jupyter Notebook exercises on covariance and correlation, simple linear regression, multiple regression and polynomial regression. I ran the original examples and made small changes to observe the results. Increasing random noise reduced Pearson correlation from 0.888 to 0.549. Changing one point in the linear-regression data affected the fitted line and prediction. I also compared CO2 predictions for two vehicle weights and saw how one altered observation reduced the polynomial model's R².

## So What?

Before this activity, I could look at a graph but found it harder to explain what the numbers meant. Working through the changes helped me understand that correlation measures association, not cause and effect, and that a fitted line depends on the observations used. I was particularly surprised that changing just one point in the polynomial example reduced R² from 0.9432 to 0.8109. I also realised that a model changing its prediction for a different input is not the same as retraining it on changed data.

## Now What?

I want to practise interpreting coefficients, checking unusual data points and testing models on data they were not trained on. In future machine learning work, including network and operational datasets, I will be more careful about describing what a score shows, what it does not show and whether the dataset is suitable for the conclusion being made.
