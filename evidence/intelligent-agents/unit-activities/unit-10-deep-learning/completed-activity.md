# Unit 10 Activity – Deep Learning in Action

## Activity Overview

This activity explored how deep learning is applied to solve real-world problems. I selected image recognition using Convolutional Neural Networks (CNNs) as the example application because it is one of the most common and practical uses of deep learning today.

The aim of the activity was to understand how deep learning models learn from large datasets, how they differ from traditional machine learning techniques, and the ethical challenges that organisations must consider before deploying AI systems.

---

## Selected Application

### Image Recognition using Convolutional Neural Networks (CNNs)

Convolutional Neural Networks are specialised deep learning models designed to process image data. Instead of relying on manually created rules, CNNs automatically learn features such as edges, shapes, textures and objects from thousands of labelled training images.

CNNs are widely used in:

- Medical image diagnosis
- Facial recognition
- Autonomous vehicles
- Manufacturing quality inspection
- Security and surveillance

As the network is trained on more examples, it gradually improves its ability to recognise similar patterns in previously unseen images.

## Benefits

Studying this application helped me understand several advantages of deep learning:

- Automatic feature extraction from raw data
- High accuracy for complex pattern recognition
- Ability to improve performance through additional training data
- Wide range of real-world applications across many industries

These capabilities explain why deep learning has become one of the most important technologies in modern Artificial Intelligence.

---

## Privacy and Ethical Considerations

While deep learning provides many benefits, the activity also highlighted several ethical concerns.

Large datasets often contain sensitive personal information such as photographs, medical records or voice recordings. If these datasets are biased or incomplete, the trained model may produce unfair or inaccurate decisions.

Key ethical issues include:

- Privacy
- Bias and fairness
- Transparency
- Accountability
- Human oversight

Developers and organisations therefore have a responsibility to ensure AI systems are trained using appropriate data, regularly monitored and deployed responsibly.
