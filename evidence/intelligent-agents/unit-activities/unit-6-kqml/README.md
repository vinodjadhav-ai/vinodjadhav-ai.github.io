# Unit 6 Activity — KQML and KIF Agent Dialogue

## Module

Intelligent Agents

## Unit

Unit 6 — Working Together

## Activity

Create a dialogue using KQML and KIF between two agents:

- Alice — an agent responsible for procuring stock.
- Bob — an agent responsible for warehouse stock levels.

Alice asks Bob:

1. whether 50-inch televisions are available;
2. how many HDMI ports the televisions have.

## Purpose

The purpose of this activity was to practise using KQML performatives and KIF-style content to represent structured communication between autonomous agents.

## Evidence Included

- `completed-dialogue.md` — the completed Alice and Bob dialogue.
- `reflection.md` — my short reflection on the activity.
- `screenshots/` — optional screenshot of the completed activity.

## Learning Outcomes Supported

- Understanding the motivation and appropriate use of agent-based computing.
- Understanding agent communication models and their grounding in AI research.
