# Unit 8 – Constituency-Based Parse Trees

This folder contains the supporting evidence for the **Unit 8 Natural Language Processing (NLP)** activity completed as part of the Intelligent Agents module.

The activity required the creation of constituency-based parse trees for three English sentences. The objective was to develop an understanding of how natural language can be represented using hierarchical grammatical structures and how this supports Natural Language Processing (NLP).

The evidence provided in this folder includes:

- The completed constituency-based parse trees for the three required sentences.
- A personal reflection describing what I learned from the activity and how it improved my understanding of NLP.

Together, these artefacts demonstrate my developing understanding of sentence structure, syntactic ambiguity and the role of constituency parsing within intelligent systems.
