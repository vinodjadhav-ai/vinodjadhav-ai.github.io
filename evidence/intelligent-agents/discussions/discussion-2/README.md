# Collaborative Discussion 2 — Agent Communication Languages

## Module

Intelligent Agents

## Units

Units 4–7

## Purpose

This folder contains the evidence collected for Collaborative Discussion 2, which focused on Agent Communication Languages (ACLs), particularly Knowledge Query and Manipulation Language (KQML), and compared them with direct method invocation in programming languages such as Python and Java.

The discussion helped me develop my understanding of:

- agent communication mechanisms;
- performatives used in KQML;
- semantic interoperability between autonomous agents;
- advantages and limitations of agent communication languages;
- comparison between loosely coupled agent communication and tightly coupled software systems.

This discussion strengthened my understanding that communication between autonomous agents is fundamentally different from communication between software components. It also highlighted that effective agent communication requires common semantics, agreed protocols and appropriate governance.
