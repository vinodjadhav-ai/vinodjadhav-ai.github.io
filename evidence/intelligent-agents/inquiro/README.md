# Inquiro Project Evidence

This folder contains selected supporting evidence for my individual Inquiro implementation in the Intelligent Agents module.

Inquiro is a multi-agent academic research assistant developed using Python, LangGraph, Ollama and the arXiv API. The system accepts a research question, creates a plan, retrieves academic papers, processes the evidence and generates a structured Markdown report.

The complete source code, dependencies and technical documentation are maintained in a separate GitHub repository:

https://github.com/vinodjadhav-ai/inquiro-multi-agent-research-assistant

This e-Portfolio does not reproduce the entire submitted assignment. Instead, it presents selected evidence of the architecture, implementation, testing, remediation and my personal learning.
